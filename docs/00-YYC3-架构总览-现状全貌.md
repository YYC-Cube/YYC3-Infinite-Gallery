## 1. 一句话画像

一个**纯静态前端**的品牌型 3D 影像画廊：Next.js 静态导出、React Three Fiber 无限滚动画廊、可拆分音视频媒体空间、7 套主题 + 可视化工作台、4 类页面小组件、PWA 离线与宿主桥接客户端。**没有服务端、没有数据库、没有登录**；所有状态在浏览器内（localStorage + IndexedDB），部署在 GitHub Pages + 自定义域名。

## 4. 状态层（全部 useSyncExternalStore 外部 store）

| Store | 持久化 | 关键职责 |
| ---- | ---- | ---- |
| `config-store` | `yyc3-gallery-config` + IndexedDB | 视觉配置、`visualOverrides` 单向优先级、背景/Logo 水合 |
| `version-store` | `yyc3-gallery-version-v1` | 7 套主题变量表、断点覆盖、布局模式、减少动效 |
| `media-store` | `yyc3-gallery-media-layout` | 内置 15 音频 + 8 视频、画廊图源、播放器布局 |
| `media-space/store` | `yyc3-media-space-v1` | 1 音频会话 + 最多 4 视频会话；`windowState`（normal/minimized/maximized）；任务坞；恢复时按 id 重取媒体地址 |
| `widget-store` | `yyc3-widget-space-v1` | 时钟/日历/天气/便签的启停、坐标、尺寸、形状、迷你态 |
| `favorites-store` | `yyc3-favorites-v1` | 收藏曲目 |
| `recommendation-store` | `yyc3-recommendation-v1` | 曝光/互动记录、亲和度对数评分、挂载时排序 |
| `annotation-store` | `yyc3-annotations-v1` | 标注缓存；远程接口缺失时用文件名启发式 |
| `i18n` | `yyc3-locale-v1` | 三语字典、`<html lang>` 同步 |
| `performance-monitor` | `yyc3-gallery-performance-v1` | Web Vitals 指标与评级 |
| `host-bridge` | `yyc3-host-outbox-v1` | 能力协商结果、离线待同步队列（上限 100） |
| `theme-port` | `yyc3-theme-presets-v1` | 主题方案快照（上限 10） |

IndexedDB：`yyc3-gallery-assets/backgrounds`（背景 + Logo Blob）、本地媒体文件库（`lib/media-db.ts`）。

## 5. 关键机制

### 5.1 主题与配置的优先级（单向）

```
主题内置变量（<style id="yyc3-theme-vars">）  ← 基础层
        ↓ 仅当 visualOverrides[字段] === true
用户配置内联变量（<html> style）              ← 覆盖层
```
`visualOverrides` 为 false 时移除内联值，主题重新生效；点「跟随当前主题」全部复位。导入主题或应用方案时，被导入的配色字段一律置为 true。

### 5.2 媒体空间

- 音频 1 个 + 视频最多 4 个会话，每个会话独立队列/进度/音量/静音/循环/随机。
- 拆分（split）与统一（unified）只改变视图归属，不重建媒体元素。
- 最小化统一收纳到底部任务坞（播放/暂停、单容器还原、全部还原）；最大化经 `createPortal` 渲染到 `body`，逃逸 unified 容器 `overflow:hidden` 裁剪。
- 内置视频全部 H.264（CRF 24），错误按 `MediaError.code` 分型并支持重试。

### 5.3 媒体地址解析

`mediaUrl(path)`：绝对 URL、`data:`、`blob:` 原样返回；其余按 `NEXT_PUBLIC_MEDIA_BASE_URL` 前缀。配置该变量即整体切换 CDN，`pnpm assets:plan` 生成外迁清单。

### 5.4 视觉工作台（Design Studio）

五个分栏：主题、外观、文字、组件、语言。能力：7 套预设主题 + 实时预览卡 + **分屏对比**；布局与断点；背景/媒体空间背景上传（assetId）；光效与边线色度；标语、**Logo 上传**（尺寸/不透明度/圆角/**跳转链接**）与**品牌字体上传**（woff2/woff/ttf/otf）；**主题导出/复制/导入**、**方案库（保存/应用/删除）**、**主色 OKLch 输入**、**主色对比度提示**、**批量对比度审计**与**一键修复**；4 类小组件启停；三语切换。

### 5.6 无障碍与品牌资产

- 对比度：`evaluateContrast`（hex/rgb/rgba/**oklch**，半透明先混合）→ 实时提示；`auditThemeContrast` 批量审计 7 项；`suggestAccessibleColor` 将主色提亮/加深至 AA 4.5:1，面板提供一键修复。
- 资源：背景、Logo、字体统一存 IndexedDB（`yyc3-gallery-assets`），配置只保存 assetId；刷新后由 `hydrateBackgrounds` 统一水合。
- 字体：`applyConfigToDOM` 注入 `<style id="yyc3-custom-font">` 的 `@font-face` 并写 `--font-brand`，缺失时回退 cormorant。


### 5.5 PWA 与宿主

- SW 预缓存 51 项静态资源；导航 Network First + 3.5s 超时回退，最后回退 `offline.html`；`sw.js` 与 HTML 不缓存。
- 更新流程：监听 `waiting`/`updatefound` → 提示新版本 → `SKIP_WAITING`。
- 宿主桥接为可选：未配置 `NEXT_PUBLIC_YYC3_HOST_URL` 时直连 + 本地缓存 + outbox 降级。

## 7. 质量门禁与部署

本地一条链：`typecheck → lint → test:coverage → docs:check → assets:check → security:check → build → test:e2e`。

CI 四 Job（`.github/workflows/deploy.yml`）：

1. **Quality Gate**：上述前六项（含 209 单测、40+ 文档、资产预算、0 漏洞）。
2. **Build**：静态导出 → 产物文件名安全守卫 → 上传 `static-out` 与 Pages 制品。
3. **E2E**：复用构建产物跑 7 条关键路径。
4. **Deploy**：仅 main push 触发；`concurrency.group=pages`；权限最小化。

站点：`https://gallery.yyc3.top`（`public/CNAME`）。安全响应头见 `public/_headers`（GitHub Pages 忽略，CF Pages/Netlify 自动生效）。

## 8. 已知边界（诚实清单）

| 边界 | 说明 | 收敛条件 |
| ---- | ---- | ---- |
| 无服务端 | 纯静态导出，无 API/DB/鉴权；宿主 `/v1/*` 由外部实现 | 需要多用户协同时评估 |
| 运行时 CSP | GitHub Pages 不支持响应头；`_headers` 需边缘层生效 | 域名接入 Cloudflare 等 |
| 资产在仓库 | `public/` 约 108.6MB（音频 67.7 / 视频 26.2 / 图片 14.6） | 对象存储 + `NEXT_PUBLIC_MEDIA_BASE_URL` |
| 主题能力 | 字体、OKLch、Logo 跳转、分屏对比、主色一键修复均已落地；仅「全量自动修复」与「设备尺寸模拟」为规划 | 有明确诉求时扩展 |
| i18n 未全覆盖 | 配置面板等仍中文 | 字典扩展 |
| WebXR 仅探测 | 无 3D 场景注入 | 有设备与场景需求 |
| AI/推荐无远程 | 本地启发式与本地统计 | 端点/行为 API 就绪 |
