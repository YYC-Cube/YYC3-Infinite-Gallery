## 4. 主题能力（G-01）

| 能力 | 实现 |
| ---- | ---- |
| 主题导出 | `buildThemePayload` 白名单提炼配色/光效/排版/动效/布局；不含背景二进制 |

## 5. 资产治理（C-03）

### 5.1 预算门禁

新增 `scripts/check-assets-budget.mjs` 与 `pnpm assets:check`，接入 CI Quality Gate。

| 维度 | 预算 | 实测 | 占比 |
| ---- | ----: | ----: | ----: |
| public 总量 | 120MB | 108.6MB | 90% |
| 音频总量 | 75MB | 67.7MB | 90% |
| 视频总量 | 28MB | 26.2MB | 94% |
| 图片总量 | 16MB | 14.6MB | 91% |
| 单文件 | 8MB | 7.55MB | 94% |
| 文件名安全 | 禁止 `: < > \| " * ?` | 通过 | — |

### 5.2 视频二次压缩决策

评估对 8 个 H.264 视频从 CRF 24 再压至 CRF 26：总量 26.2MB → 24.0MB（-8%）。

**结论：不替换。** 依据：收益仅 2MB，却引入二次编码画质损失；当前视频已满足全浏览器兼容与体积预算。真正解耦路径是 CDN/对象存储分发，而非继续在仓库内压缩。

### 5.3 迁移路径（已文档化）

| 方案 | 适用场景 | 关键动作 |
| ---- | ---- | ---- |
| 对象存储 + CDN（推荐） | 新增音频/视频/大图 | `src` 改用 CDN 绝对地址或 `NEXT_PUBLIC_MEDIA_BASE_URL` 前缀 |
| Git LFS | 必须留仓库的少量大文件 | `.gitattributes` 跟踪 `public/mp3/**`、`public/mv-*/**` |
| 构建期外链同步 | 临时过渡 | 构建前从对象存储拉取，凭证仅存 CI Secrets |

## 6. 运维基线（本次固化）

更新 `docs/deployment.md` 至 v1.1.0，新增五章：

1. **CI/CD 流水线与发布门禁**：四 Job 依赖顺序、并发与权限最小化、制品复用、产物文件名守卫、PR 只验证不部署。
2. **发布回滚手册**：四级回滚方式（revert → 重跑 Job → DNS 核对），禁止 force push 与跳门禁。
3. **静态资产治理**：预算表、实测基线、压缩决策依据、CDN/LFS 迁移路径。
4. **安全响应头与 CSP**：GitHub Pages 不支持响应头的事实与 `meta CSP` 局限；边缘层（Cloudflare/`_headers`）可直接套用的响应头模板与落地检查。
5. **监控与故障处置**：内置可观测能力清单 + 六类常见故障首查项与处置动作。
